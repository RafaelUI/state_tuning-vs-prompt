# Этапы

Папка на этап; имя начинается с даты (ММДД). В каждой — скрипты прогона и сводки, сводки (`*_summary.md`), входные данные
этапа и `outputs.tar.gz` с сырыми ответами, кэшами учителя и журналами обучения. Как запускать — [REPRODUCE.md](../REPRODUCE.ru.md).

| папка | раздел статьи |
|---|---|
| `1019_embed_fold`, `1020_embed_cut`, `1020_embed_bank` | Эмбеддер: инструкция запроса (исторические скрипты, `embed-run`) |
| `1020_neuron_0p4b` | Генерация: «Neuron» (0.4B, протоколы c1–c4, перенос формы) |
| `1022_neuron_1p5b` | Генерация: 1.5B (23.10) |
| `1027_matrix` | Масштаб × квантизация; ранняя остановка |
| `1029_prompts` | Пять разных промптов |
| `1030_provocations_control` | Провокации личности; Сильный контроль (`src/` — код TopLayerFinetune до коммита в SwiftRWKV) |
| `1031_prov_training` | Провокации в обучении |
| `1101_dialogues` | Роль во времени (`gate/` — проверки бинарников) |
| `1101_classification` | Следование инструкции: классификация 0.4B / 1.5B, кривая по объёму данных |
| `1102_audit` | Надёжность разметки |
| `1103_cost` | Стоимость |
